# Crucible

> Reproducibility asks whether the number comes out of the code.
> **Crucible asks whether the number is _real_.**

Crucible re-executes a data-driven analysis, reproduces its headline finding, then adversarially
stress-tests whether that finding holds up — checking for **data leakage**, **batch / site confounds**,
**effect-size inflation**, and **p-hacking** — and issues a **Robustness Report Card**
(`CERTIFIED` · `FLAGGED` · `INCONCLUSIVE` · `ERROR`), each verdict backed by a reproducible exhibit.

It **certifies and strengthens** findings — it doesn't scold.
